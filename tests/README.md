# Проверки базы данных

После установки и генерации данных запусти `scripts/test.sql` через psql.
Используй подключение с автоподтверждением и без открытой транзакции.
Тесты 03 и 05 откатывают свои данные, сохраняя ранее закоммиченные записи.

Проверки запускаются после соответствующих миграций:

1. `01_schema_smoke_test.sql` - проверяет полный набор таблиц.
2. `02_indexes_test.sql` - проверяет наличие заданных индексов.
3. `03_stock_transfer_test.sql` - проверяет перемещения, вместимость,
   нехватку товара и историю движений. Все добавленные данные откатываются.
4. `04_workflow_test.sql` - сверяет сгенерированные данные, проверяет запрет
   повторного проведения и изменения завершенных документов.
5. `05_edge_cases_test.sql` - проверяет полный откат при ошибке, недопустимые
   переходы статусов и частичную отгрузку. Нужны сгенерированные данные;
   добавленные тестом документы откатываются.

После миграции 06 используй актуальную версию теста 03.
Интеграционный запуск через `run_integration.py` требует пустую базу,
указанную в `TEST_DATABASE_URL`, и зависимости из `python/requirements.txt`.
Он устанавливает схему, выполняет пример и тесты, затем оставляет
небольшой набор данных для изучения.
