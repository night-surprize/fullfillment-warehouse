# Скрипты Python

Установи зависимости из `requirements.txt` и задай строку подключения
в переменной окружения `DATABASE_URL`. После применения SQL-миграций выполни:

```powershell
python python/generate_data.py --cycles 5000 --seed 0.42
```

Скрипт вызывает SQL-генератор. Данные проходят через те же процедуры,
что и обычные документы приемки и отгрузки. Повторный запуск добавляет
новый набор, сохраняя существующие данные.

Аналитические представления и запросы находятся в файлах
`sql/08_analytics.sql`, `sql/09_analytical_queries.sql` и `sql/10_explain.sql`.
