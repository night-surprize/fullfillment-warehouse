# SQL-скрипты

Для новой базы запусти `scripts/install.sql` через psql. Он применяет файлы
в следующем порядке:

1. `01_types.sql` - схема и типы ENUM.
2. `02_reference_tables.sql` - справочники.
3. `03_operational_tables.sql` - документы, остатки и история.
4. `04_indexes.sql` - индексы.
5. `05_stock_transfer.sql` - первоначальная процедура перемещения.
6. `06_operations.sql` - общий механизм проведения, приемка, сборка и отгрузка.
7. `07_document_rules.sql` - проверки документов и аудит.
8. `08_analytics.sql` - аналитические представления.
9. `11_demo_generator.sql` - процедура генерации данных.

Файлы 09 и 10 содержат аналитические запросы и сравнение планов выполнения.
Их можно запускать повторно после заполнения базы.

Установка и обновление описаны в `docs/setup.md`, вызовы процедур -
в `docs/workflows.md`. В существующей базе применяй только новые миграции.
